Android Studio WebView APK Setup Guide

How to build Android APK in Android Studio:

  1. Open Android Studio on your laptop.
  2. Click New Project → Select Empty Views Activity.
  3. Set App Name: Ultimate Joy Home, Package Name: com.ultimatejoyhome.estimate.
  4. Copy the contents of this app directory into the Android project's app/src/main/assets/www/ folder.
  5. Check the pre-made MainActivity.java and AndroidManifest.xml files inside the android/ directory created in this workspace.
  6. Click Build → Build APK(s) in Android Studio to create your offline Android app!
